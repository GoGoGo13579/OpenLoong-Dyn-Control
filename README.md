# OpenLoong 运动控制算法优化笔记

## 概述
本项目基于openloong软件框架，针对双足机器人的运动控制算法进行了优化改进，主要涉及WBC算法和MPC算法。修改内容集中在`cost_algorithm`目录下。

## 核心改进

### 1. WBC算法优化
- **软接触模式**  
  新增可选软接触模式，通过动力学WBC二次规划的目标函数和约束实现接触力平滑过渡（详见[技术笔记](./cost_algorithm/笔记/open-loong二次开发笔记.pdf)）
  - 优点：改善触地/离地过程的力变化平滑性
  - 缺点：参数整定更加复杂

- **任务优先级优化**  
  重构运动学WBC的任务优先级处理逻辑，修正期望状态设置方式（[问题分析](https://github.com/loongOpen/OpenLoong-Dyn-Control/issues/13)）

- **代码结构优化**  
  重构冗余代码

### 2. MPC算法改进
- **动力学方程重构**  
  分离重力加速度项作为常量，优化MPC模型推导（推导过程见技术笔记）

- **计算逻辑精简**  
  重构代码逻辑，移除冗余计算模块
